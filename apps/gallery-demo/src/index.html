Four Architectural Folds

Explicit Implementation Status · 13-Crate Rust Workspace
01 · IDENTITY & SCARCITY Implemented

ZIP 227 AssetDigest & Halo2 Supply Caps

Derives canonical 64-byte BLAKE2b-512("ZSA-Asset-Digest") and Pallas GroupHash("z.cash:OrchardZSA") from genesis. Deterministic mint nullifiers (NF_aid, NF_idx, NF_med) + Halo2 16-bit binary range proofs enforce capped drops.

02 · OUT-OF-BAND WRAPPING Implemented (PQ: Design Target)

O(1) Pallas ECDH Key Handover

Payloads encrypt once under ChaCha20Poly1305. Transfers re-wrap only the 32-byte DEK via ephemeral Pallas ECDH + HKDF-SHA256—moving large artworks with zero re-upload. (Hybrid ML-KEM-768 encapsulation is a planned design target.)

03 · RECURSIVE LINEAGE Implemented

Ragu Non-Uniform Recursive PCD

Integrates tachyon-zcash/ragu (WalletRank = R<13>) with specialized Step<Pasta> circuits—enforcing state contiguity, boolean creator royalties, and Poseidon Merkle ownership inside a constant 7,168 B proof.

04 · SETTLEMENT ADAPTERS Simulated In-Memory Ledger

Orchard Seal → ZSA → Tachyon

Implements ZIP 302 0xFF||"ZYOZ" memo encoding, real orchard address derivation, and 2-of-3 Pallas Schnorr threshold signing over simulated in-memory Orchard, ZSA, and 10k-mint Tachyon epoch ledgers.
